# Reference peptide

Install the package, then run from the repository root:

```bash
python examples/quickstart/run_quickstart.py --output-dir work/quickstart
```

The script checks `examples/pdb_checks/reference_peptide.pdb`, amidates its three
carboxyl groups and verifies five saved checkpoints and topology exports.
The structure grows from 46 to 79 atoms. See the
[quickstart](../../docs/QUICKSTART.md) for installation, settings and expected outputs.
